# cutie calc <3

A super simple calculator made with HTML, CSS and JavaScript, in a lavender and pink theme.


## What it does

- Adds, subtracts, multiplies and divides
- Decimals, clear (C) and delete (⌫)
- Shows a friendly "oops" when you divide by zero

## How to run it

1. Download or clone this repository
2. Open `index.html` in your browser

## Files

- `index.html` - the structure (screen and buttons)
- `style.css` - the cute lavender and pink look
- `script.js` - the calculator logic

## What I learned

- Selecting elements with `document.getElementById`
- Storing state in variables
- Handling clicks with `addEventListener`
- Using `data-` attributes to tell buttons apart
- Laying out buttons with CSS grid
